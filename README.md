# CISSP Practical Lab

## Purpose

This project is a hands-on learning platform designed to reinforce CISSP concepts through practical demonstrations, simulations, visualisations, and mini security labs.

The goal is to transform theoretical CISSP concepts into practical examples that can be explored, tested, and demonstrated.

---

## Objectives

- Learn CISSP concepts through implementation
- Build practical demonstrations for all CISSP domains
- Create a reusable study and revision platform
- Develop a cybersecurity portfolio project
- Document lessons learned during the CISSP journey

# Domain 3 - Security Architecture and Engineering

## Lab 1 - CIA Triad Simulator

### Objective

Demonstrate the impact of losing:

- Confidentiality
- Integrity
- Availability

### Scenario

Farm_Expenses_2026.xlsx

#### Confidentiality

Unauthorised viewing of sensitive farm financial data.

#### Integrity

Modification of financial records from legitimate values to incorrect values.

#### Availability

Loss of access to records due to system failure or outage.

### Lab Design

#### User Story

As a CISSP student,

I want to simulate the loss of Confidentiality, Integrity and Availability,

So that I can understand the business impact of security failures.

#### Expected Learning Outcome

Students can identify:

- Which security objective is affected
- Real-world business impact
- Typical controls used to protect each objective
