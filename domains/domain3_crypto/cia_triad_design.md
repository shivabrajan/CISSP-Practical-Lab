# CIA Triad Simulator

## Purpose

Demonstrate the three foundational information security objectives:

- Confidentiality
- Integrity
- Availability

## Scenario

Farm_Expenses_2026.xlsx

Income: ₹100,000

Expense: ₹50,000

Profit: ₹50,000

## Demonstrations

### Confidentiality

Unauthorised user gains access to the file.

### Integrity

Expense modified from ₹50,000 to ₹500,000.

### Availability

Database becomes unavailable.

## Learning Outcomes

Users should understand:

- What each CIA component protects
- What happens when it fails
- Typical controls used to protect it
